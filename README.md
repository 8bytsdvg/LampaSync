# Lampa Sync

Плагин для [Лампы](https://github.com/yumata/lampa), который синхронизирует просмотр между телевизором и компьютером через ваш **личный секретный GitHub Gist** — бесплатно и без своего сервера.

Начали серию на телевизоре — продолжили на Маке с той же минуты, и наоборот.

**Быстрый старт:** в Лампе → Настройки → Расширения → Добавить плагин:
```
https://cdn.jsdelivr.net/gh/8bytsdvg/LampaSync@main/lampa-sync.js
```
При первом запуске плагин предложит применить рекомендуемые настройки (парсер, TorrServer, плеер, плагины онлайн-просмотра и рейтингов). Потом вставьте GitHub-токен в Настройки → Синхронизация таймкодов (как получить — ниже).

Обновления приходят сами: Лампа скачивает плагин заново при каждом запуске.

## Что умеет

**Синхронизация (все устройства)**
- **Таймкоды** — где вы остановились в фильме или серии.
- **«Моя раздача»** — закреплённая раздача у фильма/сериала.
- **Последняя запущенная раздача** — для кнопки «Продолжить».
- **Основной источник** на карточке (если выбран долгим нажатием в меню «Источник»).
- GitHub — главная копия: при каждом обновлении устройство дозаливает туда всё, чего там нет (после работы без интернета, падения Лампы и т. п.).
- Кнопка **«Обновить»** в шапке (вторая, после поиска): синхронизирует всё прямо сейчас, проверяет новую версию плагина на GitHub и перезапускает Лампу — подтягиваются обновления Лампы, этого и остальных плагинов. Если синхронизация сломалась (например, отозван токен), кнопка краснеет.

**Моя библиотека** (пункты «Моя библиотека» и «Смотрю» в левом меню)
- **Просмотренное** — всё, что вы начинали смотреть, от свежего к старому.
- **Флаги** для любого фильма: Смотрю, Смотреть позже, Запланировано, Жду продолжение, Нравится, Просмотрено, Брошено — можно несколько сразу, у каждого своя категория. Метки видны на постерах.
- Поставить флаг: кнопки на странице фильма (часы — «Смотреть позже», сердце — «Нравится», книжки — все флаги) или долгое нажатие на постер → «Моя библиотека…».
- Синхронизируется между устройствами, без ограничений по количеству (в отличие от статусов CUB Premium).

**Карточка фильма/сериала**
- **«Продолжить»** — сразу запускает «Мою раздачу», а если её нет — последнюю запущенную раздачу (у сериала открывается список серий).
- **«Выбрать источник»** (лупа) — обычное меню: Торренты, Онлайн и т. д.

**Список торрентов** (долгое нажатие ОК на раздаче)
- **«Сделать „Моей раздачей“» / «Убрать»** — у фильма может быть только одна «Моя раздача»; она подсвечена и стоит первой в списке.
- **На Маке:** «Скачать: скопировать magnet-ссылку» — для вставки в qBittorrent.

**Mac + IINA**
- Лампа открывает IINA сразу с нужной минуты.
- Плагин для IINA сообщает время просмотра обратно в Лампу (через TorrServer), поэтому продолжить на телевизоре можно с того места, где остановились на Маке.

## Что нужно

| | Android TV | Mac |
|---|---|---|
| Лампа | приложение [Lampa](https://github.com/lampa-app/LAMPA/releases) | Safari → `http://lampa.mx` → Файл → «Добавить в Dock» |
| TorrServer | приложение [TorrServe MatriX](https://github.com/YouROK/TorrServe/releases) | [TorrServer](https://github.com/YouROK/TorrServer/releases) (`darwin-arm64`), см. ниже |

| GitHub | аккаунт и токен (один на все свои устройства) | |

## Установка

### 1. Токен GitHub (один раз)

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Откройте https://github.com/settings/tokens/new?scopes=gist&description=Lampa%20sync
3. **Expiration** → *No expiration*, внизу **Generate token**, скопируйте токен (`ghp_…`).

Токен даёт доступ **только к вашим Gist**. Хранится только на ваших устройствах. Отозвать можно на той же странице.

### 2. Плагин в Лампе (на каждом устройстве)

1. **Настройки → Расширения → Добавить плагин**, адрес:
   ```
   https://cdn.jsdelivr.net/gh/8bytsdvg/LampaSync@main/lampa-sync.js
   ```
2. После перезапуска: **Настройки → Синхронизация таймкодов → Ключ синхронизации** — вставьте токен.
   - На первом устройстве плагин сам создаст секретный Gist «Lampa sync data».
   - На остальных — найдёт его по тому же токену. Появится «Синхронизация подключена».

> На телевизоре токен удобно вставлять с телефона: приложение **Google TV** → значок клавиатуры → вставить.

### 3. Рекомендуемые настройки Лампы

Их применяет сам плагин: окно при первом запуске или кнопка **Настройки → Синхронизация таймкодов → Применить рекомендуемые настройки**. Что именно меняется:

- **Парсер:** включить, тип Jackett, ссылка `jac.red`, «Поиск» → «Оригинальное + год».
- **TorrServer:** ссылка `127.0.0.1:8090` (сервер на том же устройстве).
- **Плеер для торрентов:** Android TV — внешний (Just+ Player, «запомнить выбор»); Mac — IINA.
- Полезные плагины: `https://nb557.github.io/plugins/online_mod.js` (онлайн), `https://nb557.github.io/plugins/rating.js` (рейтинги КП/IMDb).

**Android TV, чтобы Лампу не выгружало во время фильма:** зажмите «Назад» в Лампе → «Включить удержание сокета»; перед фильмом закрывайте тяжёлые приложения в фоне (Spotify, YouTube).

### 4. Mac: TorrServer и IINA

**TorrServer со значком в строке меню**
```sh
mkdir -p ~/Library/Application\ Support/TorrServer
curl -L -o ~/Library/Application\ Support/TorrServer/TorrServer \
  https://github.com/YouROK/TorrServer/releases/latest/download/TorrServer-darwin-arm64
chmod +x ~/Library/Application\ Support/TorrServer/TorrServer
./torrserver-menubar/build.sh
```
После установки TorrServer **включается сам вместе с Лампой и выключается, когда вы её закрываете (⌘Q)**. Это делает фоновый помощник без значка и окон: он стартует при входе в систему, ждёт сигналов macOS о запуске/закрытии Лампы (без опроса), перезапускает сервер, если тот упал, и не оставляет его работать без Лампы. Нужен сервер без Лампы — откройте TorrServer из `~/Applications`: появится значок в строке меню (статус, «Открыть Лампу», веб-панель, «Остановить TorrServer»); открыть приложение ещё раз — тоже выключить. Когда сервер работает вместе с Лампой, значка нет. Лампа должна быть добавлена в Dock под именем `Lampa` (`~/Applications/Lampa.app`).

**Плагин для IINA**
```sh
cp -R iina/lampa-sync.iinaplugin ~/Library/Application\ Support/com.colliderli.iina/plugins/
```
Перезапустите IINA → Настройки → Плагины → включите **Lampa Sync**. Токен IINA не нужен — она общается только с локальным TorrServer.

### 5. Windows (необязательно)

Лучше всего работает **Lampa Desktop** (приложение для Windows) с внешним плеером **VLC** или **MPC-HC**: Лампа сама забирает из них время просмотра, а плагин синхронизирует его.

1. Включите в плеере веб-интерфейс: VLC — Инструменты → Настройки → «Все» → Интерфейс → Основные интерфейсы → Web, пароль `123456`; MPC-HC — Вид → Настройки → Проигрыватель → Веб-интерфейс, порт `3999`.
2. Лампа → Настройки → Плеер → тип «Внешний», путь к `vlc.exe` или `mpc-hc64.exe`.
3. TorrServer для Windows: [TorrServer-windows-amd64.exe](https://github.com/YouROK/TorrServer/releases/latest).

В обычном браузере на Windows синхронизация тоже работает, но со встроенным плеером Лампы. Подробности для доработки — в [AGENTS.md](AGENTS.md).

## Как пользоваться

- **Смотрите как обычно.** Время уходит в GitHub само: на ТВ — каждые ~2 минуты и при выходе из плеера, на Маке — не чаще раза в 30 с и сразу после закрытия IINA.
- **На другом устройстве** откройте Лампу (или нажмите «Обновить» в шапке) — через несколько секунд всё подтянется. Пока Лампа открыта, проверка идёт каждые 20 с.
- **Выход из плеера** — кнопкой «Назад» (на Маке — ⌘Q в IINA).
- Таймкод привязан к **конкретной раздаче и файлу**: чтобы продолжить на другом устройстве, запускайте ту же раздачу — проще всего через «Продолжить» или «Моя раздача».

## Ограничения

- Синхронизация **торрентов**. Онлайн-источники в «последнюю раздачу» не попадают; время из IINA передаётся только для торрентов.
- Нужен интернет; без него изменения копятся и уходят позже.
- При конфликте побеждает более свежая запись — время на устройствах должно быть правильным (обычно выставляется автоматически).

## Проблемы

| Симптом | Что делать |
|---|---|
| Кнопка обновления красная / «проверьте ключ» | Токен отозван или неверный — создайте новый и вставьте в настройках |
| На ТВ серия начинается сначала | Лампу выгрузило из памяти: включите «удержание сокета», закройте фоновые приложения, используйте Just+ Player |
| На Маке время из IINA не доходит | Запущен TorrServer? Включено «отслеживание таймкодов» в TorrServer? Включён плагин Lampa Sync в IINA? |
| Не видно «Моей раздачи» на другом устройстве | Нажмите «Обновить» в шапке |

## Что где хранится

В вашем секретном Gist: `timeline.json` (таймкоды), `pins.json` («Моя раздача»), `last.json` (последние раздачи), `settings.json` (основной источник), `library.json` (моя библиотека). Никуда больше данные не отправляются.
